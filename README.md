A top-down stealth heist drawn as a working architect's blueprint: cream drafting paper, ink walls and hatching, one vermilion accent for danger. Three rooms — Archive Hall, Ledger Vault, Loading Bay — with three routes each (vent crawl, keycard door, patrolled main floor), guards with swept vision cones, two sweeping ceiling cameras, five tools bought from a per-room budget (bolt cutter, keycard cloner, smoke can, radio decoy, soft shoes), and a mercury alarm column that turns patrols hot at 40 and fails the run at 100 with a fair freeze-frame of the cone that caught you. Steal the Marrow Ledger, take optional loot if you dare, and reach the getaway van for a scored breakdown.

## Run it

```sh
node serve.ts          # then open http://localhost:8080
node main.ts           # builds /output (game/, screenshots/, dossier.json)
```
